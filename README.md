# Калькулятор

Программа запрашивает два числа и выполняет выбранную операцию:
сложение (+), вычитание (-), умножение (*) или деление (/).

## Подготовка окружения

Откройте папку проекта:

```bash
cd ~/projects/calculator_mdk2

```

Если виртуальное окружение ещё не создано:

```bash
python3 -m venv venv
```

Активируйте окружение:

```bash
source venv/bin/activate
```

## Запуск программы

```bash
python main.py
```

Введите два числа и операцию: +, -, * или /.
Дробные числа можно вводить через точку или запятую.

При делении на ноль или вводе букв вместо чисел программа
выводит понятное сообщение об ошибке.

## Выход из виртуального окружения

```bash
deactivate
```
